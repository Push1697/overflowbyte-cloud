02 — ACCESS EVALUATION FLOW

Conditional Access decision tree for mobile requests

1. Mobile Client Signs In (Outlook / Teams)
User enters credentials on mobile device. Entra ID intercepts the authentication request.
2. Compliance Verification Check
Is phone registered in Company Portal and marked compliant? If NO: access blocked; prompt to enroll.
3. Boundary Filter (Android Work Profile / iOS Managed)
Is the app running inside the Android Work Profile or under iOS MDM? If personal side: blocked immediately.
4. Access Granted with MAM Encryption & Copy-Paste Block
Connection admitted. App Protection Policy enforces clipboard isolation, screenshot block, and biometric lock.
