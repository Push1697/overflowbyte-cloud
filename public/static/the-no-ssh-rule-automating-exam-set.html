01 — THE DISCIPLINE

Never SSH in to fix anything: automate from zero

The core principle of Week 6: you must recreate every manual environment exclusively via Ansible playbooks. If a task fails on a managed host, you are forbidden from logging in via SSH to fix it. You must diagnose the failure through playbook output, correct the YAML file, and rerun the play against clean, reverted nodes.

02 — THE AUTOMATION LOOP

Revert, run, verify, break

1. virsh snapshot-revert rhel01 clean
Both managed nodes are wiped back to their pristine post-registration baseline.
2. ansible-playbook site.yml
Execute declarative automation to provision all users, services, storage, and security policies.
3. Second Run: Assert changed=0
Rerun the playbook immediately. Any task reporting 'changed' violates idempotence and fails.
4. Sabotage Injection & Assert Verification
Intentionally corrupt firewall rules or file modes. The verification stage must catch and fail the play loudly!
