01 — ROADMAP PHILOSOPHY

Requirement-driven, not video-driven: 8 weeks to double certification

Most certification plans are a passive list of courses and slides. This plan is built entirely on verifiable requirements: every single day, you are given an outcome a server must reach, and an automated grading harness checks whether you succeeded — after a mandatory reboot.

MONTH 1
Core RHEL → RHCSA (EX200)
Weeks 1–4: files, permissions, LVM, systemd, boot recovery, and rootless Podman containers.
EX200 FOCUS
MONTH 2
Ansible Automation → RHCE (EX294)
Weeks 5–8: inventories, playbooks, variables, roles, Ansible Vault, and multi-node failure handling.
EX294 FOCUS
THE GOLDEN HABIT
Reboot Before You Believe It
Red Hat exams grade the state of the machine after reboot. If it doesn't survive restart, it scores 0.
PERSISTENCE
DOCUMENTATION REFLEX
Exam-Legal Docs Only
Build reflexes using only man, info, /usr/share/doc, and ansible-doc. No Google in the exam room.

02 — THE 8-WEEK TIMELINE

Week-by-week curriculum milestones

WEEK 1 — CORE FOUNDATIONS
Users, Permissions, SUID/SGID & Shell Navigation
PAM, credentials, ACLs, SSH keys, sudoers with visudo validation.
WEEK 2 — SYSTEM SERVICES & STORAGE
Systemd, Networking, LVM & Persistent Mounts
Physical volumes, volume groups, logical volumes, XFS expansion, NFS mounts by UUID.
WEEK 3 — SECURITY & BOOT RECOVERY
SELinux, Firewalld & The 4 Boot Failures
Emergency target, GRUB recovery, broken fstab rescue, persistent SELinux booleans and file contexts.
WEEK 4 — RHCSA CAPSTONE & EXAM
Rootless Containers, Tuned & 2.5h Mock Exam
Podman quadlets, tuned performance profiles. Bank the RHCSA credential before touching Ansible!
WEEK 5 — ANSIBLE FUNDAMENTALS
Inventories, Ad-Hoc Commands & Idempotence
Configuration files, ad-hoc administration, first YAML playbooks, verifying changed=0 on run 2.
WEEK 6 — THE NO-SSH RULE
Automating Every Month 1 Task Through Ansible
Never SSH into managed nodes to fix anything. Fix the playbook and re-run against reverted nodes.
WEEK 7 — ENTERPRISE STRUCTURE
Roles, Jinja2 Templates & Ansible Vault
Decompose monoliths into roles, multi-vault IDs, Jinja2 templating with facts, no_log security.
WEEK 8 — RHCE CAPSTONE & CERTIFY
Full Mock Exam & Production Deployment
Cross-node orchestration, rolling batch deployments, and sitting the EX294 exam.
