# Welcome to My Developer Blog

This blog is maintained inside **Obsidian** and published directly to **Hashnode** using **Google Antigravity AI Agents**.

## How this works
- **Writing**: Authored in local Markdown files with Obsidian.
- **Agent Assistance**: Antigravity agents assist with drafting, editing, tag selection, and CDN image uploads.
- **Publishing**: Pushed to Hashnode via the Hashnode MCP integration and Hashnode CLI.
